# Metrobloks

> Metrobloks, LLC is a US-headquartered developer and operator of multi-tenant colocation data
> centers in underserved metropolitan markets, built for low-latency AI inference, edge, gaming,
> streaming and other latency-sensitive workloads. It sells physical infrastructure — space, power,
> cooling and cross-connects — not software. **Metrobloks publishes no API, no developer program
> and no machine-readable specification of any kind.** This file was generated by API Evangelist
> from the company's public website; it is not published by Metrobloks.

## What Metrobloks sells

- Colocation — single-tenant and multi-tenant halls, modular and standardized design, air and
  hybrid liquid cooling, near-zero-water cooling: https://www.metrobloks.com/colocation
- Interconnection — carrier-neutral cross-connects, "IXP-like connectivity" inside the data hall,
  and a self-perform interconnect option: https://www.metrobloks.com/interconnection
- AI-ready infrastructure — high-density halls for inference at the metro edge:
  https://www.metrobloks.com/ai
- Basis of Design — announced, not yet published: https://www.metrobloks.com/coming-soon

## Sites

North America: Miami FL, Phoenix AZ, Detroit MI, Kansas City MO, Indianapolis IN, McAllen TX.
Europe: Paris. Index: https://www.metrobloks.com/all-sites

## APIs

None. There is no developer portal, no API reference, no base URL, no OpenAPI/AsyncAPI/GraphQL/MCP
surface, and no customer self-service portal advertised anywhere on the public site. Probed on
2026-08-17: `/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/api-docs`, `/docs`, `/redoc`,
`/llms.txt` and every `/.well-known/*` path all return 404, and no `api.`, `developer.`, `docs.`,
`portal.`, `my.`, `app.` or `status.` subdomain resolves. See
`well-known/metrobloks-well-known.yml` in this profile for the recorded probe.
